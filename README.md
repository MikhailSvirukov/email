# Email
Утилита, позволяющая искать и загружать письма и вложения посредством протокола imap и отправлять письма через протокол smtp
## Структура ##
Состоит из трех логических функций: 
1. ```find``` - позволяет найти письмо с помощью флагов:
   * ```--id``` - по id письма
   * ```--email``` - по адресу электронной почты отправителя
   * ```--sender``` - по имени отправителя
   * ```--date-to```, ```date-from``` - по временному отрезку, когда письмо пришло\
В качестве результата выдается список всех писем, соответствующих заданным параметрам; для каждого подходящего письма выдается отправитель, дата, тема и id
2. ```get``` - позволяет загрузить письмо по указанному id.
   Принимает единственный аргумент - id письма. Письмо сохраняется в указанную в файле config.py папку, где (при необходимости, aka отсутствие этих папок),
   будут созданы еще 2 уровня вложенности - **emailsender/date/** - для удобства организанции хранения. Сам текст письма загружается в файл ***text.txt*** (первой строкой идет тема сообщения), сюда же выгружаются вложения.
3. ```write``` - позволяет отправить письмо с помощью флагов:
   * ```--source``` - название папки по заданному в config.py пути, из которой будет сформировано сообщение; файл ***text.txt*** - текст сообщения (первая строка - тема), остальные файлы - вложения
   * ```--to```, ```--group``` - соответственно, адрес единственного отправителя и название файла, в котором с новой строки написаны несколько адресов
## Config.py ##
* ```mail``` - адрес электронной почты отправителя
* ```password``` - пароль от почты
* ```server_imap``` , ```server_smtp```- адрес сервера для подключения по протоколу imap и smtp соответственно (например, imap.mail.ru для mail.ru)
* ```folder_save``` - папка, в которую загружаются текст и вложения письма
* ```folder_save``` - папка, в которой происходит поиск паки для формирования письма для отправления
* ```base_dir``` - папка проекта
